# truesky-legal

Support and privacy pages for [TrueSky](https://apps.apple.com/app/truesky-weather/id6816346955), an iPhone weather
app that paints the hourly forecast as a landscape. The pages are served with GitHub Pages:

- Support: https://msliwa01.github.io/truesky-legal/
- Privacy policy: https://msliwa01.github.io/truesky-legal/privacy.html

Plain HTML and one CSS file, in English and Polish.
